# Demo video script (2 minutes max)

**Published:** https://youtu.be/bm-QA92K8MQ (1:46). Thumbnail: docs/video-thumbnail.jpg.

Record the live site at phone width. On a laptop: Chrome → F12 → device toolbar → 390 px wide, then record with
Windows Snipping Tool (**Record**) or Xbox Game Bar (Win + Alt + R). On a phone: the built-in screen recorder.
Speak slowly; about 270 words fits in 2 minutes. Upload as **Unlisted** on YouTube and put the link at the top of README.md.

Before recording: open every screen once so it loads fast, and keep this message ready to paste:

> Guaranteed admission at Oxford Brookes, no IELTS needed, total cost 25 lakh, PR in UK in 2 years.
